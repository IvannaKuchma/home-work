# Express Templates Demo

## Опис
Сервер на Node.js + Express з підтримкою **PUG** (для користувачів) та **EJS** (для статей).

## Маршрути
- `/users` – список користувачів (PUG)
- `/users/:userId` – деталі користувача (PUG)
- `/articles` – список статей (EJS)
- `/articles/:articleId` – деталі статті (EJS)

## Встановлення
```bash
git clone <repo-url>
cd express-templates-demo
npm install
npm start
