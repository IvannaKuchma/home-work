# React Базовий Проєкт

Цей проєкт створений для ознайомлення з основами React. Він містить простий компонент — кнопку або текстове поле — який демонструє використання props.

## Технології

- React
- JavaScript / TypeScript
- Vite або Create React App 
- CSS

## Клонування репозиторію

## Встановлення залежностей:
npm install або yarn

## Запуск проєкту:
Якщо ви використовуєте Vite: npm run dev
Якщо Create React App:npm start

## Відкрийте в браузері:
Відкрийте браузер і перейдіть за адресою: http://localhost:5173/
або (для CRA): http://localhost:3000/

## Тестування:
У проєкті також додано базовий тест для перевірки рендерингу React-компонента:npm test
