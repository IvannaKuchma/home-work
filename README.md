# Проєкт: MongoDB + Mongo Express

## Опис проєкту
Цей проєкт створений для роботи з базою даних MongoDB та її веб-інтерфейсом Mongo Express.  
Він дозволяє:

- Запуск MongoDB у Docker-контейнері.
- Використання Mongo Express для зручного перегляду та редагування бази даних через браузер.
- Збереження даних MongoDB між перезапусками контейнерів через Docker volumes.

Проєкт підходить для навчальних цілей або тестування додатків, які працюють з MongoDB.

---

## Завдання проєкту
1. Налаштувати Docker-середовище з двома сервісами: `mongo` і `mongo-express`.
2. Запустити базу даних MongoDB з логіном `root` та паролем `example`.
3. Підключити веб-інтерфейс Mongo Express для управління базою.
4. Переконатися, що дані зберігаються між перезапусками контейнерів.
5. Використати сучасний формат Docker Compose без застарілого ключа `version`.
