# Passport Session Project

Це простий проект на **Node.js** та **Express.js** з підтримкою **Passport.js**, сесій і захищених маршрутів.

---

## Технології

- Node.js
- Express.js
- Passport.js (Local Strategy)
- express-session
- Pug (шаблони)
- bcrypt (хешування паролів)
- dotenv
- nodemon (для розробки)

---

## Структура проекту

passport-session-project/
├─ node_modules/
├─ public/
│ └─ favicon.ico
├─ views/
│ ├─ index.pug
│ ├─ login.pug
│ └─ register.pug
├─ server.js
├─ package.json
├─ .env
└─ README.md
