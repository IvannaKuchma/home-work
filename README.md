# Опис
Цей проєкт — це адаптивний веб-сайт, зверстаний на HTML і SCSS відповідно до макету з Figma. Він демонструє мої навички у верстці, використанні CSS-анімацій та роботі з грідами і флексбоксом.

#Функціонал
- Повністю адаптивний дизайн (Desktop, Tablet, Mobile)
- Використання SCSS для стилізації
- Динамічні ефекти через CSS (без JavaScript)
- Оптимізована структура коду
- Кросбраузерна підтримка (Chrome, Firefox, Edge, Safari)

# Використані технології
- HTML5
- SCSS (SASS)
- CSS Grid & Flexbox
- GitHub Pages (для деплою)
